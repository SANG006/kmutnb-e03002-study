# เตรียมสอบเข้าเตรียมวิศวะ มจพ. E03002

เว็บเตรียมสอบเข้า ปวช. เตรียมวิศวกรรมไฟฟ้าและอิเล็กทรอนิกส์ โปรแกรมภาษาไทย E รหัส 03002 รอบโควตาเรียนดี ปีการศึกษา 2570

แผน DAY 01–18 ครอบคลุม 10–27 พฤศจิกายน 2569 มี 74 บทเรียนและข้อสอบพร้อมเฉลย 445 ข้อ แบบฝึกทั่วไปจับเวลา 40 นาที ข้อสอบจำลอง DAY 15 และ DAY 17 มีชุดละ 40 ข้อ จับเวลา 120 นาที ส่วน DAY 18 ใช้ทบทวนและเตรียมสัมภาษณ์

## เปิดบน Windows 11

1. แตก ZIP แล้วเปิด PowerShell ในโฟลเดอร์ที่มี README นี้และโฟลเดอร์ `docs`
2. รันคำสั่งต่อไปนี้ หากเครื่องใช้คำสั่ง `python` ให้แทน `py` ด้วย `python`

   ```powershell
   py -m http.server 8080 --bind 127.0.0.1
   ```

3. เปิด [เว็บบนเครื่อง](http://127.0.0.1:8080/docs/) คงหน้าต่าง PowerShell ไว้ระหว่างใช้ และกด Ctrl+C เมื่อต้องการหยุด

หน้า **แผน 18 วัน** ใช้ค้นหัวข้อหรือกรองวิชา แต่ละวันมีบทเรียน ตารางอ่าน และหน้าทำข้อสอบของวันนั้น เลือกฝึกทำ จับเวลา หรือฝึกทบทวนที่เปิดเฉลยทีละข้อได้ คะแนนเป็นผลฝึกส่วนตัว ข้อที่ถูกได้ 1 คะแนน ข้อที่ผิดหรือเว้นได้ 0 คะแนน

เว็บเก็บบทที่อ่านและผลรอบล่าสุดแยกตามวันในเบราว์เซอร์ หากต้องการย้ายเครื่อง ให้เปิด **ความคืบหน้า → ชื่อวัน → ส่งออก JSON** แล้วนำเข้าในวันเดียวกันบนเครื่องปลายทาง ข้อมูลผูกกับ URL และโปรไฟล์ของเบราว์เซอร์ แบบทดสอบแบบ Static ส่งเฉลยไปพร้อมไฟล์ข้อมูลของวันนั้น ผู้ใช้จึงสามารถเปิดข้อมูลเฉลยผ่านไฟล์เว็บได้

## แก้ไขและทดสอบ

| ตำแหน่ง | เนื้อหา |
| --- | --- |
| `docs/data/curriculum.json` | สารบัญ วัน จำนวนบทและข้อ สัดส่วนรายวิชา และเวลาของแต่ละชุด |
| `docs/data/day01-*.json` และ `docs/data/sources.json` | ข้อมูล DAY 01 ที่นำมาจากฉบับต้นแบบที่อนุมัติ |
| `docs/data/days/02.json` ถึง `18.json` | บทเรียน ข้อสอบ เฉลย หน้าอ้างอิง บรรณานุกรม และรูปประกอบของแต่ละวัน |
| `docs/downloads/` และ `docs/figures/` | PDF ต้นฉบับและกราฟหรือวงจรที่ตัดจากหน้าเอกสาร |
| `docs/assets/` | ส่วนแสดงผล เส้นทาง URL แบบ hash และตรรกะตรวจคะแนนกับจับเวลา |
| `scripts/import_pdfs.py` | สร้าง JSON สำหรับ DAY 02–18 จากชุด PDF รวมรายวัน ด้วย Python และ pypdf 6.10.2 |
| `tests/` | ชุดตรวจข้อมูลครบทั้ง 18 วันและตรรกะของแบบทดสอบ |

ใช้ UTF-8 และรักษารหัสตัวเลือกเมื่อแก้ JSON ตัวตรวจคะแนนใช้รหัสตัวเลือกใน `correct` ตำแหน่งที่ปรากฏบนเว็บเป็นไปตามลำดับในอาร์เรย์ `options` หลังแก้ให้ตรวจโจทย์ ตัวเลือก และเฉลยร่วมกัน

```powershell
node --test --test-isolation=none tests/day01.test.mjs tests/full.test.mjs
```

หากต้องนำเข้าจากชุด PDF ใหม่ ให้ใช้ `python scripts/import_pdfs.py <โฟลเดอร์ที่แตกชุด-PDF-รายวัน>` แล้วตรวจผลด้วยชุดทดสอบและตรวจรูปประกอบกับหน้าต้นฉบับ

## GitHub Pages

เว็บเป็น Static และโหลดข้อมูลตามวันที่เปิด ใช้พาธสัมพัทธ์และจุดเริ่มต้นที่ `docs/index.html` หากสร้าง repository ใหม่บน GitHub Free ให้เลือก **Public** และอัปโหลดทั้งโฟลเดอร์โดยรักษา `docs/.nojekyll` ไว้ จากนั้นเลือก **Settings → Pages → Deploy from a branch → main → /docs → Save** หลังเผยแพร่ให้กด **Visit site** และลองเปิดลิงก์ตรง `#day/17/quiz` กับดาวน์โหลด PDF

การอัปเดตให้แก้และทดสอบก่อน commit ไปที่ `main` จากนั้นตรวจการเผยแพร่ใน **Actions** ผลตรวจข้อมูลและการใช้งานอยู่ใน [QA_REPORT.md](QA_REPORT.md)
